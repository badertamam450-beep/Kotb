تطبيق أندرويد إسلامي تفاعلي حديث مبني باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3** وتوافق كامل مع **Android 15 (SDK 35/36)**.

---

## 🌟 مميزات التطبيق

1. **تدقيق لغوي وإملائي بنسبة 100%**:
   - مراجعة وتصحيح شامل لجميع صفحات الكتاب الـ 16 وفق قواعد الإملاء العربي ومخارج الحروف وضبط الهمزات والترقيم.
2. **تصميم وهوية إسلامية فاخرة**:
   - إطارات ذهبية مذهبة وزخارف أرابيسك مستوحاة من المصاحف والكتب التراثية الفاخرة.
   - دعم 4 سمات ومظاهر لونية:
     - 🌙 الكحلي الملكي والذهب (Midnight Gold)
     - 🌿 الزمردي الإسلامي (Royal Emerald)
     - 📜 الورق العتيق / سبيا (Warm Parchment)
     - 🖤 الأسود الداكن (Pure Dark)
3. **أوضاع قراءة متعددة**:
   - **وضع الصفحات الفردية (١ - ١٦)**: تصفح يحاكي الكتاب الأصلي مع شارات ترقيم دائرية.
   - **وضع القراءة المتصلة**: تمرير انسيابي لكامل موضوعات وأبواب الكتاب.
   - إمكانية تكبير وتصغير حجم الخط من 14pt إلى 28pt.
   - تغيير نمط الخط (نسخ كلاسيكي / خط النظام الواضح).
4. **القارئ الصوتي الذكي (TTS)**:
   - الاستماع الصوتي التلقائي لكل صفحة مع إمكانية التحكم في سرعة الصوت (0.75x إلى 1.5x) والإيقاف والتشغيل والتنقل.
5. **فهرس ذكي وبحث فوري**:
   - بحث لحظي في كامل النصوص والموضوعات مع الانتقال المباشر.
   - تبويبات منظمة للفصول والصفحات والعلامات المرجعية.
6. **درر واقتباسات جاهزة للمشاركة**:
   - بطاقات اقتباسات ملهمة للمشاركة المباشرة عبر واتساب وتيليجرام وغيرها.
7. **حفظ تلقائي وإشارات مرجعية**:
   - تذكّر تلقائي لآخر صفحة تمت قراءتها عبر `SharedPreferences`.
8. **معلومات المؤلف والتواصل**:
   - بطاقة متكاملة للمؤلف د. مالك الرميمة مع إمكانية الاتصال المباشر بنقرة زر واحدة.

## 📱 متطلبات التشغيل

- **نظام التشغيل**: Android 7.0 (Nougat / API 24) فما فوق.
- **موصى به**: Android 14 / 15 (SDK 34/35/36).
- **لغة البرمجة**: Kotlin 2.0+
- **واجهة المستخدم**: Jetpack Compose (Material 3).

---

## 🛠️ كيفية البناء والتشغيل محلياً

```bash
# 1. استنساخ المستودع
git clone https://github.com/<your-username>/<repo-name>.git

# 2. الدخول لمجلد المشروع
cd <repo-name>

# 3. بناء ملف الـ APK التجريبي (Debug APK)
./gradlew assembleDebug

# 4. تثبيت التطبيق على الهاتف المتصل عبر USB
./gradlew installDebug
```

مسار ملف الـ APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

---

## 🚀 البناء التلقائي عبر GitHub Actions

المشروع يحتوي على سير عمل مجهّز بالكامل (`.github/workflows/build-apk.yml`) يقوم عند كل `push` أو `release` بـ:
1. إعداد بيئة Java 17 و Android SDK.
2. بناء حزمة `APK` جاهزة للتثبيت المباشر.
3. رفع ملف الـ APK كـ **Artifact** أو إرفاقه تلقائياً في الـ **Releases** مع رابط تحميل مباشر.
